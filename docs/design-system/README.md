## Referencia aprobada
La maqueta conceptual aprobada contiene cuatro pantallas: Inicio, Proyectos, Detalle de proyecto y Servicios. Es una referencia estética, no una especificación literal. No reproducir el marco de iPhone, la barra de estado ni contenidos, tecnologías o imágenes ficticias.

**Archivo de referencia original:** `mobile-approved-concept.png` (recurso gráfico complementario; debe añadirse bajo `references/` cuando se incorpore al repositorio). Los documentos textuales son la fuente normativa hasta entonces.

## Principios
- Estética clara, minimalista y de producto mobile premium.
- Construir confianza mostrando webs reales y explicando el servicio.
- Una familia de tipografía, otra de iconos y tokens semánticos.
- No inventar testimonios, tecnologías, estadísticas ni resultados.
- Mantener desktop intacto durante las primeras etapas.
- No modificar Foco Financiero, panel, APIs ni autenticación.
- Una etapa por vez, con validación visual manual antes de avanzar.
