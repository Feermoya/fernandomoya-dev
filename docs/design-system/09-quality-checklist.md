# 09 · Checklist

## Visual
- [ ] Hero explica el servicio inmediatamente.
- [ ] Familia tipográfica e iconografía consistentes.
- [ ] Paleta, radios, sombras y espacios desde tokens.
- [ ] Proyectos legibles a 375px, imágenes auténticas.
- [ ] Sin marcos telefónicos ni capturas inventadas.
- [ ] Sin columnas estrechas con párrafos truncados.
- [ ] Secciones compactas y claras.

## UX
- [ ] Navegación y acciones funcionales.
- [ ] CTA comercial visible.
- [ ] Objetivos táctiles >=44px y foco visible.
- [ ] Menús y modales accesibles.
- [ ] Contraste WCAG AA.
- [ ] Reduced motion.
- [ ] Contenido esencial sin JS.

## Técnico
- [ ] Desktop intacto durante la etapa mobile.
- [ ] Panel, Foco Financiero, APIs y autenticación intactos.
- [ ] Datos de proyectos desde una fuente única.
- [ ] URLs, canonical, sitemap y SEO conservados.
- [ ] Imágenes optimizadas, sin CLS evidente.
- [ ] Typecheck y build o errores previos documentados.
- [ ] Sin deploy ni pruebas online.
