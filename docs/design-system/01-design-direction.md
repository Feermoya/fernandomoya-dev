# 01 · Dirección de diseño

## Idea
**Quiet premium / product-grade portfolio.** Sitio para contratar desarrollo web con precisión visual y fluidez de aplicación, sin copiar una interfaz nativa.

Palabras guía: claro, preciso, contemporáneo, sobrio.

## Sensación
- Profesional confiable y cercano.
- Fondos hielo, superficies blancas, textos azul-negro y acentos cobalto.
- Tipografía sans contundente y legible.
- Capturas de proyectos reales, con proporciones controladas.
- Tarjetas elegantes y microinteracciones discretas.

## Objetivo comercial
El usuario entiende, en este orden: qué hago, para quién, trabajos reales, servicios concretos, contacto directo.

## Evitar
Dark theme como identidad principal, títulos serif decorativos, gradientes exagerados, glassmorphism, una captura gigante ocupando el primer viewport, métricas inventadas, nav inferior forzada, marcos de teléfono, cards anidadas, textos vacíos y patrones de dashboard.

## Atemporalidad
El estilo no debe depender de tendencias puntuales de 2026: tokens semánticos, componentes adaptables y contenido real. La imagen de concepto guía la composición, pero estos documentos establecen las decisiones implementables.
