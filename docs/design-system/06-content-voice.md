# 06 · Contenido y voz

Español argentino natural, profesional y cercano. Frases cortas, beneficios concretos y sin promesas vacías. Hablar a negocios y profesionales, no a desarrolladores.

## Copy propuesto, sujeto a revisión
- Hero: «Sitios web modernos para negocios reales».
- Bajada: «Soy Fernando Moya. Diseño y desarrollo sitios web para mostrar tus servicios, presentar tus productos y recibir consultas».
- CTA: «Ver proyectos» / «Hablemos de tu web».
- Proyectos: «Proyectos» o «Trabajos recientes».
- Servicios: «Soluciones web para cada necesidad».
- Sitios: «Presentá tu negocio y facilitá que te contacten».
- Catálogos: «Mostrá tus productos de forma clara y organizada».
- Plataformas: «Herramientas web adaptadas al funcionamiento de tu negocio».
- Contacto: «¿Tenés un proyecto en mente? Contame qué necesitás y vemos cómo encararlo».

## Datos reales
Nombre, categoría, textos e imágenes desde `src/content/projects/`. Descripción de tarjeta: qué es, para quién y función confirmada. No inventar stacks, resultados, métricas, testimonios, disponibilidad o mejoras SEO. No convertir la página en una narración extensa, pero conservar texto útil para usuarios y buscadores.
